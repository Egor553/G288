# 📄 Документация проекта «Со мной» (DoggyService Marketplace)

В этом файле описана архитектура проекта, процесс деплоя, команды управления и структура хостинга.

## 🏗 Архитектура

Проект представляет собой **Fullstack Web Application**, оптимизированное для работы в качестве **Telegram Mini App**.

### Стек технологий:
- **Frontend**: React 19 + TypeScript + Vite.
- **Styling**: Tailwind CSS + Framer Motion (для плавной анимации).
- **Backend**: Node.js + Express (файл `server.ts`).
- **Database**: Prisma ORM + SQLite (файл `prisma/dev.db`).
- **Icons**: Lucide React.
- **Hosting**: Vercel.

---

## 🚀 Хостинг и Деплой

Приложение развернуто на платформе **Vercel**. 

### Как работает загрузка:
1. Вы запускаете команду деплоя.
2. Vercel собирает фронтенд (Vite build) и запускает серверную часть как Serverless Functions.
3. База данных SQLite хранится локально в проекте (для продакшена рекомендуется переход на PostgreSQL, но сейчас используется файл).

### Основная команда для обновления сайта:
```bash
npx vercel --prod --yes
```
*Эта команда отправляет все текущие изменения кода на живой сервер.*

## 💻 Команды управления

### Локальная разработка:
Запуск проекта на вашем компьютере:
```bash
npm run dev
```

### Работа с Базой Данных (Prisma):
Если вы изменили схему данных в `prisma/schema.prisma`:
1. **Генерация клиента**: `npx prisma generate`
2. **Синхронизация с базой**: `npx prisma db push` (обновляет таблицы без удаления данных)
3. **Визуальный интерфейс БД**: `npx prisma studio` (открывает базу в браузере)

После обновления кода выполните `npx prisma db push`, чтобы создать таблицы: Report, RefreshToken и поля User.tokenVersion, User.blockedAt, Booking.serviceId.

### Сборка проекта:
```bash
npm run build
```

## 📂 Структура проекта

- `/src` — Весь фронтенд код (React компоненты).
  - `/components` — Кнопки, формы, профили, чат.
  - `/lib` — Утилиты (например, `api.ts` для запросов).
- `server.ts` — Серверная часть приложения (API эндпоинты, авторизация, уведомления в ТГ).
- `prisma/schema.prisma` — Описание таблиц базы данных (Юзеры, Питомцы, Услуги, Заказы).
- `.env` — Файл с секретными ключами (Токен бота, JWT секрет, URL админа).

---

## 🤖 Интеграция с Telegram

У нас настроен Mini App. Для корректной работы уведомлений в файле `.env` должны быть:
- `TELEGRAM_BOT_TOKEN` — Токен вашего бота.
- `ADMIN_TELEGRAM_ID` — ID человека, который будет одобрять заявки специалистов.
- `APP_URL` — Ссылка на деплой (например, `https://doggyservice-app.vercel.app`).

## 🛠 Полезные советы по файлам

- **Логи сервера**: Можно смотреть в панели управления Vercel (Logs).
- **Статика**: Все картинки и ассеты хранятся в `/public` или генерируются через API (заглушки).
- **Безопасность**: Для входа используется JWT токен и refresh-токен (в `localStorage`). В профиле доступна кнопка «Выйти везде».

### Новые возможности (март 2026)
- **Оферта и политика** — страницы в приложении, чекбоксы при регистрации и при оформлении заказа.
- **Валидация и rate limit** — на API включены лимиты запросов и проверка данных (zod).
- **Поиск** — по категории, городу, метро и тексту.
- **Жалобы** — кнопка «Пожаловаться» в карточке специалиста; в админке раздел «Жалобы» и блокировка пользователей.
- **Аналитика** — в админке: заказы за период, выручка, топ специалистов.
- **Напоминания** — cron `/api/cron/reminders`: уведомления за день и за час до визита (Telegram + email). Задайте `CRON_SECRET` в Vercel и настройте Cron (например, каждый час).
